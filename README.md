# assetflow-enterprise

A modern full-stack IT & Software Asset Management (SAM) SaaS platform built with React 19, Tailwind CSS, Express, and MongoDB. Streamline company hardware lifecycles, global employee hardware allocations, licensing renewals, and active maintenance ticketing in a stunning Swiss-modern unified dashboard.

## Architecture Overview

- **Primary Language:** TypeScript
- **Core Engine:** Built on Nexus-Enterprise v3.0 modular runtime.

## Getting Started

```bash
npm install
npm run dev
```
